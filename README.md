# Static Website Deployment using GitHub Pages

## Project Description
This project demonstrates how to deploy a simple static website using GitHub Pages. The website is built using basic front-end technologies and hosted publicly for free.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Live Website
https://abhishek-20051221.github.io/-Abhishek-20051221-.github.io/

## Repository Link
https://github.com/Abhishek-20051221/-Abhishek-20051221-.github.io

## Deployment Steps
1. Created a public repository named <username>.github.io
2. Cloned the repository locally using Git
3. Added website files (index.html, style.css, script.js)
4. Committed and pushed files to GitHub
5. Enabled GitHub Pages (main branch, root folder)
6. Accessed the live website using the provided URL

## Learning Outcome
- Understanding version control using Git
- Managing repositories on GitHub
- Deploying static websites
- Learning the basic deployment workflow
